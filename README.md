# ページ全体スクリーンショット（Chrome拡張 / MV3）

右クリックからページ全体を撮影し、**PNGをそのままクリップボードへコピー**するChrome拡張。
ダウンロードフォルダにファイルを落とさないのが目的。

DevToolsのフルページ撮影も「PDFに保存」も、使い捨てのつもりでも一度ファイルが残る。
その削除の手間をゼロにしたくて作った。

## できること

- 自動でスクロールしながら1コマずつ撮り、**等倍で合成**する（縮小しないので文字が潰れない）
- 合成したPNGをクリップボードに直接書き込む（貼り付け先で `Ctrl+V`）
- 撮影中に固定ヘッダー・追従要素を退避させ、同じ帯が何度も写り込むのを防ぐ
- 遅延読み込み（lazy load）を先に発火させる下見パスを1回入れる

## 入れ方

パッケージ化していない拡張として読み込む。

1. このリポジトリをクローン、またはZIPでダウンロードして展開する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選ぶ

## 使い方

1. 撮りたいページで右クリック →「ページ全体をスクリーンショット」
   - 右クリックを禁止しているページでは、ツールバーのアイコンをクリックするか `Alt+Shift+S` でも同じように撮れる（キーは `chrome://extensions/shortcuts` で変えられる）
2. 自動でスクロールしながら撮影される（**この間はページを触らない**）
3. 右下にトーストが出たら完了 → 貼り付け先で `Ctrl+V`

- 撮影中に中止したいときは `Esc`（撮影が終わったあとの貼り直し待ち20秒の間は効かない）
- **撮影したページ**がフォーカスを失っていると書き込めないため、その場合はページを1回クリックすると貼り直す（20秒待つ）
- タブ切り替え・最小化は検知して中止する（別ウィンドウを眺めるだけなら問題ない）

## 制約（仕様として割り切っている点）

- **1コマあたり0.6秒が下限**。Chromeの `captureVisibleTab` が1秒2回までに制限されているため、これ以上は速くできない。描画の落ち着き待ちを含めた実測は1コマ約0.9秒で、40コマの縦長ページなら40秒前後かかる
- 上限は **80コマ / 全体3分 / canvas 1辺32767px・面積16384²**。超えたときは縮小せずエラーで止める（黙って画質を落とさない方針）
- 撮れないページ = `chrome://` 系、Chromeウェブストア、`http://`（`http://localhost` は除く。クリップボードAPIがsecure context専用のため）
- `file://` は拡張の詳細画面で「ファイルのURLへのアクセスを許可する」をONにすれば撮れる
- ページ内に独自のスクロール領域を持つUI（チャットアプリなど）は、その領域の隠れた部分だけ撮れない。その場合はトーストに「〜を除いて」と明示される

## 権限

| 権限 | 用途 |
|---|---|
| `contextMenus` | 右クリックメニューの登録 |
| `activeTab` / `scripting` | 実行したタブにだけ撮影スクリプトを注入し、そのタブの表示範囲を撮影する |
| `clipboardWrite` | 合成したPNGの書き込み |
| `notifications` | content scriptを注入できないページでの失敗通知 |

ホスト権限は要求しない。実行したタブ以外は触らないし、外部への送信も一切しない。

## 構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3のマニフェスト |
| `background.js` | サービスワーカー。メニュー登録、スクリプト注入、1コマ分の撮影代行 |
| `capture.js` | 本体。スクロール制御・固定要素の退避・等倍合成・クリップボード書き込み |

MV3のサービスワーカーは寿命が短いため、状態は持たせず撮影のロジックは全て `capture.js` 側に寄せている。
